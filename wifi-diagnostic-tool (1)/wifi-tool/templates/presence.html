How This Works

  • Idea: a person moving through the space disturbs the radio path to nearby routers/access points, which shows up as extra volatility in each one's reported signal quality — the same principle behind WiFi/RF "device-free" sensing.
  • Signal used: this deliberately does not use your laptop's own link quality to its connected router. A background scan (netsh wlan show networks mode=bssid) runs every few seconds and reads a live signal-quality figure for every router/AP currently broadcasting nearby — yours and any visible neighbors. Motion sensing takes the standard deviation and jitter of each router's recent readings, then averages across all of them.
  • Best results: keep the laptop/adapter stationary, sit still for a baseline reading, then walk through the room to see the score react. More visible routers generally means a more stable reading.
This reads only the coarse 0–100% quality figure Windows exposes per router via netsh — not raw channel state (CSI). It's a fun, low-cost experiment, not a calibrated sensor: other WiFi traffic, moving devices, microwaves, and even weather can shift the score, and it can't count, locate, or identify anyone. Don't rely on it for security or safety decisions.
